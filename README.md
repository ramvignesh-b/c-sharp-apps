# Fun C# Projects

A repo of random-yet-fun apps built on C# (don't jusdge me, I was in junior year :3)

## Projects

This repository contains the following projects:

*   **Bounce Ball:** A simple game/simulation where balls bounce around the screen.
*   **Match:** A tile-matching or memory game.
*   **MultiApp:** A central launcher application for many of the other projects in this repository.
*   **Paint App:** A basic application for drawing and creating simple images.
*   **Profile:** An application for creating and managing user profiles.
*   **Queries:** An application to interact with a database and run queries.
*   **SlideShow:** An application to display images in a slideshow format.

## MultiApp Details

The `MultiApp` project is a Windows Forms application that serves as a dashboard or launcher for several other applications in this repository. You can use it to easily access and run the following:

*   Paint App
*   SlideShow
*   Profile Manager
*   Match Game
*   Bouncing Ball Game
*   DB Queries Tool

## How to Run

These projects are built using C# and Windows Forms. To run them, you will likely need:

*   Microsoft Visual Studio (Community Edition or higher).
*   The .NET Framework installed on your Windows machine.

The primary way to run the suite of applications is through the `MultiApp` project:

1.  Open the `multiApp/multiApp.sln` solution file in Visual Studio.
2.  Build the solution (this should build `MultiApp` and its dependencies).
3.  Run the `MultiApp` project from Visual Studio.

Alternatively, you might be able to run the pre-compiled main application directly from `multiApp/bin/Debug/multiApp.exe` if all dependencies are correctly placed.
